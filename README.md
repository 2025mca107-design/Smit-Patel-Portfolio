# Smit Patel — Internship Portfolio

A clean, responsive, black-and-white portfolio built with plain HTML, CSS and vanilla JavaScript. Typography uses Space Grotesk and Inter.

## Run locally
1. Extract the ZIP.
2. Open the `smit-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Included sections
- Introduction and internship availability
- About and technical skills
- AI-Powered Resume Screening & Job Portal project
- Personal developer portfolio project
- MCA education
- Contact form with browser and JavaScript validation

## Before you publish
1. Replace `assets/profile-placeholder.svg` with your own professional photo (keep the same filename, or update its path in `index.html`).
2. Add your latest resume PDF at `assets/resume.pdf`.
3. Replace `YOUR_EMAIL@example.com` in `index.html` and `js/script.js` with your real email address.
4. Review the project description and technology list so they accurately reflect what you can demonstrate in an interview.
5. Test all links and the contact form on desktop and mobile.

## Contact form note
This is a static website. The form validates the visitor's name, email and message, then opens their email application using a `mailto:` link. It does not send or store messages on a server.

## Publish
You can deploy this static site using GitHub Pages, Netlify or Vercel. No build step is required.
